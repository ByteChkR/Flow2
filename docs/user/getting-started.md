# Erste Schritte

[Home](../) / **Erste Schritte**

Ein Flow ist ein Graph aus Nodes. Nodes haben Eingänge, Ausgänge und gegebenenfalls Kontrollflussanschlüsse. Verbinde kompatible Ausgänge mit Eingängen und starte den Graphen im Editor.

1. Neuen Graphen im Workspace anlegen und einen passenden Namen vergeben.
2. Nodes aus der Toolbox auf die Fläche ziehen.
3. Datenports verbinden; rote Hinweise zeigen fehlende Pflichtwerte oder inkompatible Typen.
4. Für primitive Eingänge bei Bedarf den Inline-Wert aktivieren. Eine externe Verbindung deaktiviert den Inline-Wert, löscht ihn aber nicht.
5. Vor dem Start **Prüfen** wählen. Der Editor zeigt Fehler, Warnungen und Informationen nach Kategorie gefiltert an.
6. Eine passende Ausführung auswählen und starten.

Die [Standard-Node-Referenz](../generated/nodes/index.html) beschreibt die vom Paket bereitgestellten Nodes. Ein Adam-Host kann zusätzliche fachliche Nodes anbieten.
