# Versionierte Beispiele

Unter `v1` liegen die Entity-Definitionen (`types.json`), der deklarative Node-Katalog
(`catalog.json`) sowie ein interaktiver und ein Backend-Flow. Beide werden gegen
Schemas und Porttypen geprüft und in C# und TypeScript ohne Inhaltsverlust serialisiert.
Die Konfiguration von `input.contactId` ist deklarative Beispieldaten; eine browserübergreifende
Ausführung ist noch nicht angebunden. Semantik: [Vertrag v1](../README.md).
